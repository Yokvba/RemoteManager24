1. Put/replace the start.sh & startserver.sh in your Minecraft server path.
2. Then run the following commands giving permission:

sudo chmod +x ./start.sh && sudo chmod +x ./startserver.sh


You can access your minecraft server using:

screen -x mcserver
> Use CTRL + A + D to opt out of it.
> Use CTRL + C to kill the server.
> The Server will automatically restart after 5 seconds, if not wanted press CTRL + C again.

You can allocated Ram, and Server.jar File in the startserver.sh. Do not change anything else.
Only change the start.sh if really know what to.
